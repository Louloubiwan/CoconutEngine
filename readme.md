# Coconut Engine

Coconut Engine is an experimental game engine developed by **Louloubiwan Studio**, written in **Rust** using [WGPU](https://github.com/gfx-rs/wgpu).

The engine primarily targets **Vulkan** as its graphics backend.

## Status

Coconut Engine is currently in early development and mainly serves as an experimental project for exploring game engine architecture and graphics programming.
